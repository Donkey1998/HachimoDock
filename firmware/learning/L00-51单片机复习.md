## 零基础补给站

| 术语 | 一句话解释 |
|---|---|
| 单片机（MCU） | 把 CPU、内存、外设集成在一颗芯片里的微型计算机 |
| 8051 / 51 | Intel 1980 年发布的 8 位内核架构，教学界的"Hello World"，常见型号 AT89C51、STC89C52 |
| 8 位机 | CPU 一次处理 8 个二进制位（1 字节），寄存器都是 8 位的 |
| 晶振 12MHz | 芯片的心跳；经典 51 的 1 个机器周期 = 12 个时钟周期 = 1μs |
| 哈佛结构 | 程序存储器（ROM）和数据存储器（RAM）分开编址，各有各的地址空间 |

## 讲解

### 0.1 编程模型速览：你当年每天摸的东西

**寄存器**：CPU 里屈指可数的几个"手上暂存格"——累加器 A、寄存器 B、R0–R7（四组×8 个，靠 PSW 切换）、数据指针 DPTR（16 位，唯一能寻址 64K 外部的）、栈指针 SP、程序计数器 PC。8 位机的世界很小，小到可以全部背下来。

**SFR（特殊功能寄存器）**：操作外设的唯一手段。外设的每个"旋钮"都映射成一个固定地址的寄存器，往里写值就是拧旋钮：

| SFR | 管什么 |
|---|---|
| P0–P3 | 四个 8 位并行 IO 口（P0 常接总线需上拉，P1 最常用来点灯） |
| TMOD/TCON | 定时器模式/控制 |
| TH0/TL0、TH1/TL1 | 两个定时器的高/低字节初值 |
| SCON/SBUF | 串口控制/数据缓冲 |
| IE/IP | 中断使能/优先级 |

**位寻址**：51 的招牌能力——可以单独操作某个位：`sbit LED = P1^0;` 之后 `LED = 0;` 只改 P1 的第 0 位，其余 7 位不动。这在 32 位机上反而要靠"读-改-写"实现。

### 0.2 四个经典外设复习（每个都配"ESP32 翻译"）

**① GPIO 点灯**：

```c
sbit LED = P1^0;
void main() {
    LED = 0;        // 低电平点亮（灌电流接法）
    while (1);
}
```

翻译到本项目：`gpio_config()`（配置方向——51 时代 P1 天生就是 IO 无需配置）→ `gpio_set_level(GPIO_NUM_x, 0)`。**51 的 `P1 = 0xFE;` 一次控制 8 个脚，ESP32 一次一个脚，但多了方向/上拉/驱动能力配置。**

**② 定时器**：三步曲——TMOD 选模式（模式 1 = 16 位）、TH0/TL0 装初值、TR0 = 1 启动。数满 65536 溢出，硬件置标志 TF0（开了中断则进中断服务函数）。

翻译到本项目：FreeRTOS 的 `vTaskDelay(ms)` 和 `esp_timer`。**51 需要手算初值、手动重装；ESP32 上毫秒级的"定时"是操作系统的基础服务，一句函数调用。**

**③ 中断**：`EA = 1; EX0 = 1;` 打开总闸和分闸，信号来了 CPU 保存现场跳去执行 `void isr() interrupt 0`，完事返回。铁律：**中断里越短越好**（当年老师说"中断里别 delay"）。

翻译到本项目：ISR + 任务通知——ISR 里只发一个"唤醒信号"，真正的活在普通任务里干（第06课练习5 会用到这条纪律）。**这条铁律穿越 40 年不变。**

**④ 串口**：SCON 设工作方式，波特率靠定时器 1 溢出率产生，发一个字节 `SBUF = c;` 完了查 TI 标志，收靠 RI 标志或中断。

翻译到本项目：UART0 @ 4,000,000 波特，ESP-IDF 的 uart 驱动自带中断、环形缓冲、DMA——**你当年手搓的一切都成了驱动层的内置功能**（第09课）。

### 0.3 内存图：51 vs ESP32-P4

| | 51（AT89C51） | ESP32-P4（本项目） |
|---|---|---|
| 程序 | 4KB Flash ROM | 32MB Flash，**分区表**切成 8 个区（第01课） |
| RAM | 128B 内部 + 可扩 64K 外部 | 片上 SRAM + 32MB PSRAM |
| 掉电保持 | 无（RAM 数据全丢） | NVS/SPIFFS 把数据写进 Flash 分区 |
| 变量放哪 | `data/idata/xdata` 关键字手工指定 | 编译器自动；`heap_caps_malloc` 按能力分配 |

51 时代"断电即丢"逼出了 EEPROM 外挂；ESP32 用分区表+文件系统优雅解决——**这是第01课分区表练习的深层背景**。

### 0.4 51 思维的遗产与局限

**遗产（你的先发优势）**：寄存器直觉、位运算、中断纪律、"资源有限所以要省"的本能。后面读到 `gpio_set_level`、位标志、ISR 约束时，你的肌肉记忆会回来。

**局限（本课程要升级的）**：51 没有操作系统——一个 `while(1)` 裸奔一切；没有优先级——中断和主循环就两层；外设少——不需要分层抽象。ESP32-P4 外设多了两个数量级，所以需要：**驱动组件分层**（第02课）+ **RTOS 多任务**（第03课）。不是你当年做错了，是问题规模变了。

## 练习（全部纸笔题，不需要开发板）

1. **📍阅读**：读下面这段 C51，回答三问：LED 的闪烁周期是多少？亮灭占空比？这是共阳还是共阴接法？

```c
sbit LED = P1^0;
void delay1ms();  // 软件延时约 1ms
void main() {
    unsigned char i;
    while (1) {
        LED = 0;
        for (i = 0; i < 100; i++) delay1ms();
        LED = 1;
        for (i = 0; i < 300; i++) delay1ms();
    }
}
```

2. **📍阅读**：`P1 = 0xFE;` 和 `sbit LED = P1^0; LED = 0;` 效果有什么区别？`0xFE` 的二进制是什么？
3. **🔍计算**：经典 51（12MHz、12T、定时器模式 1/16 位），要定时 50ms，TH0/TL0 初值应装多少？（提示：机器周期 1μs，50ms 需要数多少个周期？65536 减去它，再转十六进制）
4. **💭翻译**：把"定时器中断每秒翻转一次 LED"翻译成 ESP32 + FreeRTOS 的两种写法（伪代码即可）：一种用任务+`vTaskDelay`，一种用主循环分频（参考第04课主循环 1ms 节拍的做法）。
5. **💭对比**：51 的 `while(1)` 大循环里同时轮询按键和串口，和本项目的"输入任务 + UART 任务分开"，各自怎么处理"按键查询耗时会拖慢串口响应"这个问题？

## 自测与参考答案

- **练习1**：周期 400ms（100+300），亮：灭 = 1:3（占空比 25%）；低电平亮 = 灌电流/共阳式接法（LED 阳极接 VCC）。
- **练习2**：`P1 = 0xFE`（二进制 1111 1110）会**顺带把 P1 其他 7 位都置 1**——如果其他位接了别的器件就被打扰；sbit 只动第 0 位。这就是"整字节写"与"位操作"的差异，嵌入式的经典坑。
- **练习3**：50ms = 50000 个机器周期；65536 − 50000 = 15536 = 0x3CB0，所以 TH0 = 0x3C、TL0 = 0xB0。
- **练习4**：写法一：`void led_task(){ while(1){ toggle(); vTaskDelay(pdMS_TO_TICKS(1000)); } }`；写法二：主循环每 1ms 一圈，计数器累计到 1000 翻转一次并清零（本项目 `main/pet_p4_main.c:748-853` 正是这种分频模式）。
- **练习5**：51 里只能把按键查询写得尽量快或上中断，串口响应时间不可控；本项目输入和串口是**不同优先级的独立任务**，调度器保证串口任务不被按键拖累——这就是 RTOS 的存在意义（第03课）。
